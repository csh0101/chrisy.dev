# Code Is All You Need

AI 时代，开发不该停留在对话、截图、文档和口头共识里。真正能被验证、复现、部署和传承的，只有 code。Prompt 可以启发方向，模型可以加速推演，但系统最终必须落到仓库、测试、接口、配置和运行状态中。Code 是事实，也是边界；它记录决策，暴露问题，承载迭代。把 code 作为唯一事实，才能让 AI 协作从灵感变成工程。
